# Frontend — Dashboard + AI Assistant UI

## Phân công

| Folder | Người phụ trách | Mô tả |
|--------|----------------|-------|
| `components/Dashboard/OverviewDashboard/` | **Đế** / Quân / Hiếu | KPI cards, tổng quan toàn quốc |
| `components/Dashboard/TrendDashboard/` | **Quân** / Đế / Hiếu | Biểu đồ xu hướng theo năm/tháng |
| `components/Dashboard/GeoDashboard/` | **Hiếu** / Quân / Đế | Bản đồ tỉnh/vùng |
| `components/Dashboard/CorrelationDashboard/` | **Quân** / Đế / Hiếu | Biểu đồ tương quan giữa các biến |
| `components/AIAssistant/` | **Thịnh** | Chat panel, code review, kết quả |
| `services/api.js` | **Thịnh** | Axios calls tới backend |
| `store/` | **Thịnh** | State management |
